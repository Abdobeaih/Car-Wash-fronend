# Design system — "Wash day" direction

Grounded in the product's subject: water, foam and the clean car after the wash
(replacing the previous warm cream/terracotta coffee-shop palette).

## Color
- porcelain `#F4F7F7` (gray-50) — page background, the "after wash" clean white
- petrol `#0E2A31` (black) — ink, dark panels, footer, hero overlay
- teal brand scale anchored on brand-600 `#0E6672` — primary actions, links
- aqua accent `#17BFA6` (aqua-500) — the single bright accent: check marks,
  selection, small highlights only
- mist `#D8E1E1` (gray-200) — borders and dividers
Semantic green/amber/red scales unchanged.

## Type
- Display: Barlow Semi Condensed 500–700 (highway-signage grotesque), sentence case
- Body: Barlow 400–700
- Arabic: IBM Plex Sans Arabic 400–700
No all-caps display treatments; no tracked-out eyebrow labels; no arrow-suffixed
links. Table headers keep small-caps as a structural table convention.

## Components
- Buttons/inputs: rounded-lg; cards rounded-2xl; badges rounded-full
- `.eyebrow`: small semibold teal, sentence case
- `.display-title`: Barlow Semi Condensed semibold, sentence case
- Hero: petrol duotone photo overlay, aqua check marks on the feature list
- Decorative index numbers removed (kept only for the real 3-step sequence)
